Wireframes · v1.5

The CreatorHub web app, drawn end-to-end with magazine-grade typography, gamified engagement, and a full-screen storytelling reader.

12 packs covering full mobile parity (auth, feed, discover, booking, studio, publishing, KYC, profile) plus two web-first surfaces — gamification (quests · streaks · XP · leaderboard) and immersive longform storytelling for itineraries. Pure White + Coral monochrome design system, Fraunces + Inter type pair, Framer Motion choreography. Approximately 120 screens.

Coral lockdown · 7 contexts

  1. 1Primary CTAs · book, publish, save changes, "Show N results"
  2. 2Active bookmark icon · filled state
  3. 3Location pin · city pin chip, results destination indicators
  4. 4Active nav indicator · top-bar tab underline, sidebar active item
  5. 5Critical unread signals · notif badge, active-filter count
  6. 6XP · streak progress fill · web only · gamification user-state
  7. 7Reading-progress bar · web only · immersive reader content-state

Motion language · Framer Motion 11

  • 120 msMicroflickhover, active, fill
  • 180 msChipstabs, toggles, segment fill
  • 220 msPageroute transitions, fadeSlide8
  • 300 msDrawerside panels, sheets, accordion
  • 480 msHerolanding reveal, chapter cards
  • spring280 / 26number-rolls, button press
  • spring180 / 18confetti, level-up burst

All variants gated by useReducedMotion() — fallback = instant state change.
