Floating top nav with WhatsApp as first-class · DD-019
Four buttons on the hero: back, WhatsApp share (dedicated icon, green fill), generic share, save bookmark. WhatsApp is its own button because Indian users share predominantly on WhatsApp — a dedicated button saves a tap. Requires Open Graph metadata on all public URLs for preview cards to render.
Title block · Airbnb pattern
Eyebrow (content type · vertical) → Fraunces title → inline meta row (rating, review count, starting city). Rating star is ink-filled (not coral — coral is reserved). Location pin is coral (one of the 5 coral contexts).
Creator chip · between title and facts
Promoted above the quick facts grid because trust in the creator is the primary conversion driver. Avatar, name, verified checkmark (if KYC done), trip count, languages. Follow button on the right is secondary (ink dark, not coral) — primary action on this screen is Book, not Follow.
Quick facts · 2×2 grid · DD-013
Four facts in a sunken card: duration, group size, difficulty, best season. Each has an icon + label + value. Tight vertical spacing. Removed the colorful vertical-tinted cards from earlier drafts — monochrome system means these all share the same warm neutral background.
Upcoming departures rail · DD-021
Horizontal scroll of date pills. Each pill: month / day / year / status ("4 spots left", "Available", "Sold out"). The selected date has a 2px ink border. Capacity (spots_booked out of capacity) comes from the scheduled_dates table. The sticky bottom bar reflects the currently selected date — if none selected, shows "From ₹X" (base price).
Meeting point · privacy-preserving · DD-021
Shows neighborhood-level description ("Manali Volvo stand area") but NOT the exact coordinates. Exact location is shared via booking confirmation email 24hr before departure. Schema: meeting_points.area_point is public, exact_location is private. This is the Airbnb / solo traveler privacy pattern.
Sticky bottom booking bar
"From ₹24,000" in Fraunces with tabular numerals, coral "Check availability" primary CTA on the right. The bar stays pinned during scroll. Guests (not logged in) who tap Check availability trigger the soft auth wall (DD-016). Logged-in users proceed to the booking flow (Screen 05, pending).
