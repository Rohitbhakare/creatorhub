1. Easing curves

Three curves cover most of the app. Avoid linear easing — it always feels mechanical. Spring for celebratory motion only.

easeOut [0.22, 1, 0.36, 1]

easeInOut [0.65, 0, 0.35, 1]

spring stiffness: 280, damping: 26

// motion-language.jsx — shared variants export const easings = { out: [0.22, 1, 0.36, 1], inOut: [0.65, 0, 0.35, 1], }; export const springs = { gentle: { type: 'spring', stiffness: 280, damping: 26 }, bouncy: { type: 'spring', stiffness: 180, damping: 18 }, // confetti, level-up };

6. Cursor-aware tilt

Cards on feed and discover pages tilt ±2° toward the cursor. Disabled on touch — tilt without a cursor is a glitch.

9. When to animate (and when not to)

Motion is a tool. It clarifies state changes, signals success, and makes long pages feel alive. It doesn't fix layout problems and it doesn't substitute for clear UI.

✓ Animate

  • ●
    Primary CTAs on successBooking confirmation, level-up, achievement unlock — confetti spring earns its keep here.
  • ●
    Page transitionsTells the user "the route changed" without disorienting them. fadeSlide8, 220ms.
  • ●
    Optimistic UISave, like, follow — animate the success state instantly. Snap back if the server fails.
  • ●
    Scroll reveals on long pagesReader, marketing, studio dashboard — once-only, with stagger. Adds rhythm to scroll.
  • ●
    MicrointeractionsBookmark fill, ring burst, coin spring, streak flame breathing — tiny, frequent, character-building.

✕ Don't animate

  • ●
    Validation errorsThe user needs to see the error, not get distracted by motion. Static red border + inline message.
  • ●
    Security warningsAnything safety-critical (private mode, deletion confirm, refund) should be static and unambiguous.
  • ●
    Layout shifts that affect CLSDon't animate height/width during layout. Animate transforms (opacity, translate, scale) only.
  • ●
    Persistent loops on idle UILooping breathing flames are fine. Looping CTAs are noise. Loops belong to ambient elements only.
  • ●
    Screen-reader-only contentaria-hidden content shouldn't be animated; visible-but-decorative motion can confuse assistive tech.
