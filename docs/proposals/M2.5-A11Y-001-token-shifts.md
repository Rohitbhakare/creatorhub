# Proposal — Design-Token Shifts to Clear M2.5/A11Y-001

> Status: **DRAFT — awaiting design call**
> Author: Claude (post-axe-sweep, 2026-05-02)
> Tracks: [M2.5/A11Y-001](../epics/TRACKING.md#open-bugs--enhancements) (P2)
> Owner: design + founder

## 1. Problem (one paragraph)

The post-M2.5 axe sweep against 13 non-legal routes returned **0 critical / 250 failing elements** for one rule — `color-contrast` (WCAG 1.4.3). Two patterns drive nearly all 250:

1. **White-on-coral at body size.** `.ch-btn-primary` and `.ch-pill-coral` use `--primary` (`#e15a41`) as background with white text at 13.5px regular. Measured 3.65:1 — fails AA's 4.5:1 minimum and is too small to qualify for the "large text" 3:1 exemption (needs ≥18pt regular or ≥14pt bold).
2. **`--ink-muted` on tinted surfaces.** `--ink-muted: #7a7a82` (Paper theme) measures 4.69:1 on pure `--surface: #ffffff` — passes AA. But on `--surface-alt: #f2f1ee` (linen), it drops to ~4.36:1 — fails. Used in card subtitles, captions, footer text everywhere a tinted bg is in play.

The 250 nodes are concentrated in `/discover` (81), `/discover/results` (34), `/creators` (24), `/content/[id]` (18); all four lean heavily on coral pills + muted card-meta text on tinted surface-alt cards.

**Why this is a token problem, not a per-callsite problem:** every offending element consumes one of three tokens (`--primary`, `--primary` via `.ch-pill-coral`, `--ink-muted`). Shifting the tokens fixes 250 nodes in one CSS edit. Per-callsite fixes would touch 100+ files and leave the design system internally inconsistent.

## 3. Proposal — three minimal shifts

### Shift A: introduce `--primary-text-bg` (locked white-text safe)

Add a new token specifically for "white text on coral" surfaces (CTAs, coral pills). Keeps `--primary` as-is for accents and decorative usage where contrast doesn't matter.

```css
:root, [data-theme="paper"] {
  --primary: #e15a41;          /* unchanged — accents, focus rings, brand mark */
  --primary-deep: #b9401e;     /* unchanged — hover state */
  --primary-tint: #fcebe6;     /* unchanged — soft pill bg */
  --primary-text-bg: #c44726;  /* NEW — bg for white-text usages, 4.55:1 */
}
```

Used in:
```css
.ch-btn-primary { background: var(--primary-text-bg); }   /* was: var(--primary) */
.ch-btn-primary:hover { background: var(--primary-deep); }  /* unchanged */
.ch-pill-coral { background: var(--primary-text-bg); color: white; }  /* was: var(--primary) */
```

**Visual impact:** the pillar coral CTAs go from `#e15a41` (orange-leaning) to `#c44726` (slightly more red-saturated). Side-by-side test recommended; in isolation, neither reads as "wrong". Brand identity stays "coral" — no shift to brown/red territory.

**Math (sRGB):**
- `#c44726` luminance ≈ 0.181 → contrast on white = 4.55:1 ✓
- One step deeper than `#e15a41` (L ≈ 0.245), one step lighter than `#b9401e` (L ≈ 0.143)

### Shift B: bump `--ink-muted` slightly darker

```css
:root, [data-theme="paper"] {
  --ink-muted: #6c6c74;  /* was #7a7a82 — passes AA on all three surface tints */
}
```

| New value | On `--surface` | On `--surface-alt` | On `--surface-sunk` |
|-----------|---------------|--------------------|--------------------|
| `#6c6c74` | 5.39:1 ✓ | 5.01:1 ✓ | 4.74:1 ✓ |

**Visual impact:** `--ink-muted` text reads marginally darker. Difference is sub-perceptual to most users; designers comparing samples will notice the muted captions are "a touch deeper". This *is* the visual change axe is asking for — there's no contrast-passing version that looks identical.

### Shift C: per-theme application

Same shifts applied to the three other themes. Numbers per theme:

| Theme | Current `--primary` | Proposed `--primary-text-bg` | Current `--ink-muted` | Proposed `--ink-muted` |
|-------|---------------------|------------------------------|----------------------|------------------------|
| Paper | `#e15a41` (3.65) | `#c44726` (4.55) | `#7a7a82` (4.36 on alt) | `#6c6c74` (5.01 on alt) |
| Snow  | `#e85a41` (3.61) | `#c4472a` (4.51) | `#6e7683` already AA on alt (4.93) | unchanged |
| Bone  | `#c9502a` already AA (4.50) | unchanged | `#7b7565` (4.16 on alt) | `#6c6755` (4.85) |
| Ink Night | `#d97b1a` against dark text — different math; needs separate audit |

Three of four themes need only the first shift; Bone already has a deep-enough primary. Ink Night (dark mode) wasn't covered by the sweep — separate audit.

## 4. Implementation

**Files touched:** [`apps/web/src/app/globals.css`](../../apps/web/src/app/globals.css) only. ~8 lines added (new token in 3 themes), ~6 lines edited (token swap on `.ch-btn-primary` + `.ch-pill-coral`), ~3 lines edited (`--ink-muted` value in 3 themes).

**No component-level changes.** Every consumer reads through the token, so the shift propagates without per-callsite work.

**Effort:** 30 min including the per-theme tweak; 30 min for visual diff at 5 breakpoints; 30 min for axe re-sweep + verifying we hit 0 violations.

**No DB / API change. No test churn** (unit tests don't assert exact hex values).

## 5. Validation plan

1. Apply the three shifts in `globals.css`.
2. Run `pnpm exec node tests/axe-sweep.mjs` — target: **0 critical, 0 serious** across all 16 routes.
3. Visual diff at 1440px against current `dev`: side-by-side screenshots of `/`, `/discover`, `/content/[id]`, `/signup`, `/u/[username]`. Flag any change that pushes the brand visibly off-center.
4. Theme-switch test: cycle Paper → Snow → Bone → Ink Night, confirm coral feels recognizable in each.
5. High-contrast media query (`prefers-contrast: more`) regression check — coral allow-list spots 1, 4, 5 still hit per WEB-A11Y-FR-110.

If step 2 returns 0/0, the system-wide AA gate closes — M2.5/A11Y-001 ships.

## 6. Open questions (founder/design call)

Before I touch tokens, three calls I want to confirm:

1. **Are we OK shipping a slightly-darker coral on CTAs and pills?** If "no, the existing coral is sacred", the fallback is per-callsite text-size bumps (≥18.66px bold on every CTA + pill) which would fight the v3 visual hierarchy. I'd recommend the token shift.
2. **One token (`--primary-text-bg`) or just darken `--primary` itself?** Adding a sibling token preserves the existing coral for accents, focus rings, and the brand mark; darkening `--primary` is a one-line change but shifts every coral element on the page. I'd recommend the sibling token (Shift A as written).
3. **Defer Ink Night audit?** The sweep didn't cover dark mode. Easy to schedule a second sweep; not blocking the light-theme fix.

If you sign off in principle, I'll implement Shifts A + B + C, run axe to confirm 0/0, screenshot the diff, and ship as a single commit. Should land in ~90 min including the visual review.

---

## 7. What this proposal is *not*

- Not a full design-system refactor. Two tokens, one new token, three themes touched.
- Not a typography change. CTAs and pills stay 13.5px regular — the contrast win comes from bg, not type.
- Not a coral-allow-list change. Spots 1 (CTAs), 2 (kickers), 3 (italic accents), 4 (active nav), 5 (critical), 6 (quest ring), 7 (tag pills) all stay on coral; just slightly deeper coral on the white-text variants.
